## 版本概览

`v3.0.6` 是一个体验修复版，全部来自用户反馈。两条主线：

- **看得见**：14 寸笔记本开着系统缩放时，定时任务列表一屏只剩两三行；「已锁定」标签被拆成两行；点操作列的 ⋯ 之后整行按钮会偏掉。
- **认得出**：订阅拉下来的 `.mjs` 脚本压根不建任务，`.js` / `.sh` 建了任务但名字全是文件名。

另外新增一个小功能：订阅的**拉取前指令**。

## 修复

- **小屏下定时任务列表一屏只能看两三行**。

  典型场景是 14 寸笔记本：物理分辨率 1920×1080，系统缩放 150%，浏览器实际拿到的是 **1280×720** 的等效视口。此前只能靠浏览器缩放硬看。

  > 根因是宽度分配，不是行高本身。表格里固定宽度的列（选择框、状态、最后运行、下次运行、上次结果、耗时、操作）合计吃掉 930px，留给「任务名称 / 命令 / 定时规则」这三个弹性列的只剩 90px，于是三列全部被压到各自的下限：命令换到 5 行、名称后的标签换到 3 行、Cron 表达式也换行，单行高度从 50px 涨到 94~186px，同时还多出 134px 横向溢出。

  现在窗口宽度低于 1600px 时自动进入紧凑模式（**移动端的卡片视图不受影响**）：

  - 隐藏「最后运行」「耗时」两列；
  - 命令与定时规则单行显示，超出部分省略，鼠标悬停可看全文；
  - 收紧单元格上下内边距，并隐藏与「定时规则」列重复的任务类型标签；
  - 重新分配三个弹性列的宽度配比，让长度固定的 Cron 表达式完整显示。

  同样是 1280×720，实测完整可见行数从 3~4 行提升到 **9~10 行**，行高回到 37px（带标签的行 62~88px），横向溢出消失。窗口宽度 1600px 以上的显示与此前**逐项一致**，没有任何变化。

  > 需要你知道的取舍：**紧凑模式下「最后运行」和「耗时」这两列在列表上看不到了**。这两个值在任务详情弹窗里仍然完整保留，但如果你习惯在列表上扫这两列，把浏览器窗口拉宽到 1600px 以上即可恢复。同样被隐藏的还有任务名后面的「常规定时 / 手动运行」标签——它和右边「定时规则」列的内容是重复的。

- **「已锁定」标签被拆成两行**。

  `v3.0.5` 新增的订阅锁标签，锁图标和「已锁定」三个字各占一行，标签高度是旁边普通标签的两倍。

  > 根因在 Element Plus 自带的一条样式：它给「可关闭标签的关闭按钮」写了 `display: flex`，但选择器命中的是标签里的**任意**图标。图标因此变成块级盒子，把后面的文字挤到第二行。

  修法是全局的，所以同一批受影响的地方一起修好了：定时任务列表（桌面表格与手机卡片）、任务详情弹窗、配置文件页的「已保存」标签。

- **点操作列的 ⋯ 之后，整行按钮会左移、最左边的按钮被裁掉**。

  现象是点开「更多」下拉之后，那一行的按钮组整体偏了一点，最左边的「运行」被切掉一截，而且**不会自己复位**，于是这一行和其它行再也对不齐；下拉菜单还会顶到浏览器窗口的最右边。

  > 根因是两份间距叠加：按钮组用的是 flex 的 `gap`，而 Element Plus 自带的 `.el-button + .el-button` 又额外加了 12px 外边距，连续四个按钮凭空多吃 36px，按钮组因此超出「操作」列的可用宽度。这一列是 `overflow: hidden`，超出后它就变成了一个可滚动容器——点最右边的 ⋯ 时，浏览器会把获得焦点的按钮"滚"进可视区，整行就这么偏了。

  现在清掉了那份重复的外边距、适当加宽了操作列，并让下拉菜单右对齐触发按钮。顺带修掉的是「前四个按钮间距 16px、编辑与 ⋯ 之间只有 4px」的不一致。

  > **订阅管理页的同一个问题也一并修了**，而且那边更严重：不用点任何东西，「拉取」和「删除」两头就已经被裁掉一截。

- **订阅拉取时 `.mjs` 脚本不建任务，`.js` / `.sh` 的任务名没匹配上**。

  三个现象其实是两个独立的原因：

  > **`.mjs` 完全不建任务**，是因为系统设置里「拉取文件后缀」的历史默认值是 `py js sh ts`，漏了 `mjs`。这一项决定了订阅同步时扫描哪些脚本，`.mjs` 连扫描都进不去——文件其实拉下来了，只是不会变成任务。
  >
  > **任务名没匹配**，是因为解析任务名的代码此前**只认**青龙的 `new Env('名称')` 写法，完全没有解析注释头的能力，于是一路回退成「去掉扩展名的文件名」。对比之下 Cron 是能认注释头的——这正好解释了「定时对了、名字不对」这个组合。

  现在：

  - 默认的「拉取文件后缀」补上了 `mjs`；
  - 任务名支持注释头声明，覆盖这些写法：

    ```
    //name: 远程开机          // name: 雀巢会员
    #name: 每日签到           ## name: DDNS IP更新
    * name: 京东比价          @name: 标签写法
    <!-- name: 网页任务 -->
    ```

  > **升级须知（会影响已有任务的名字）**：升级后的第一次拉取，那些名字还是文件名、并且脚本头写了 `// name:` 的任务**会被改成注释里的名字**——这正是这次要修的东西。已经加了订阅锁的任务（你手动改过名称或定时的）不受影响，仍然保留你的命名。
  >
  > **存量实例的「拉取文件后缀」只在你没改过它的时候才会自动补 `mjs`**。判断依据是库里存的值是否正好等于旧默认 `py js sh ts`。如果你自己调整过这一项（哪怕只是加了个 `go`），升级不会动它——请到「订阅管理 → 设置 → 拉取文件后缀」里手动补上 `mjs`。这么设计是为了不覆盖「故意不要某个后缀」的意图。
  >
  > 两点解析规则上的取舍：
  >
  > - **脚本里同时有 `new Env('A')` 和 `// name: B` 时，取 `new Env` 的 A**。这是为了让老用户升级后已有的任务名一个都不被改掉。想让注释头生效，把 `new Env` 那行去掉即可。
  > - **注释头必须带注释标记**（`//`、`#`、`*`、`--`、`@` 之一），裸写的 `name: xxx` 不认。因为 JS 里 `{ name: 'foo' }` 这种对象字面量太常见，宽松匹配会把它误当成任务名。

## 新增

- **订阅：拉取前指令**。

  订阅原本就有「拉取后钩子」，这一版补上了对称的前置入口：在 `git` 拉取**之前**执行一段 Shell 命令，适合做「准备环境 / 挂载目录 / 换源 / 生成凭据」这类动作。

  可用变量与拉取后钩子完全一致（`$SUB_DIR`、`$SCRIPTS_DIR`、`$QL_DIR`、`$SUB_NAME`、`$SUB_URL` 等），从青龙抄来的绝对路径同样会被自动改写成 `$SUB_DIR`。执行输出会带 `[pre]` 前缀进拉取日志。

  > **前置指令执行失败（非 0 退出）会中断本次拉取并记为失败，不会继续 `git` 拉取。** 这是刻意的：前置指令通常是在准备拉取所需要的环境，它没跑成功还继续拉，拉下来的东西多半也是错的，静默继续只会更难查。
  >
  > 首次拉取时订阅目录还不存在，此时 `$SUB_DIR` 会退回脚本根目录。

## 内部改动

- 模块外壳版本保持 `3`——本轮没有改动任何 `Magisk/*.sh`，**不需要重刷模块 ZIP**，一键在线升级即可。
- 接口文档补上了订阅的 `pre_script` / `hook_script` 两个字段说明。
- 新增 3 个测试文件，覆盖注释头的 9 种写法、3 类误判防线、命名优先级、系统配置迁移的三种情形，以及前置指令的日志前缀 / 失败语义 / 空值不执行。
