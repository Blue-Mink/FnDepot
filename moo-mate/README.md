# Moo Mate

Moo 的伴侣应用：把第三方 GitHub / Gitee 仓库里的 FPK 应用变成 Moo 可安装的应用源，免去手工上传 GitHub 的繁琐流程。

## 简介

Moo Mate 是一个轻量的本地伴生服务。粘贴一个第三方仓库（或 Release / 目录）链接，它会自动探测其中打包的飞牛（fnOS）应用，生成符合 Moo 源协议的 `moo.json` 并在本机托管，一键把该源加入同机的 Moo——不必手工编辑 JSON，也不必自己维护一个 GitHub 仓库。

与 Moo 相同的访问模型：点应用图标走平台统一网关（`/app/moo-mate`），
TCP `127.0.0.1:38108` 仅在回环监听，用于本机调试与本机 Moo 拉取源索引，不对局域网暴露端口。

## 功能特点

- **仓库发现**：粘贴 GitHub / Gitee 仓库、Release 或目录链接，自动识别其中打包的 FPK 应用与版本信息；支持一次贴多行（最多 10 条）批量处理
- **Gitee 目录形态**：release 停更的仓库也能发现——自动读取仓库内 `server-data/apps/` 等目录下的 FPK，与 release 资产合并去重（目录优先），可发现应用数量大幅提升（此前只能拿到 release 里的少量包）
- **索引托管**：生成符合 Moo 源协议的 `moo.json`，由本机 HTTP 直接对外提供
- **一键加源**：写入同机 Moo 的源列表，装好即可在 Moo 中浏览与安装
- **批量同步 / 批量推送 / 批量删除**：对已纳管应用做批量操作，并逐个检查上游是否有新版本
- **图标自动补齐**：优先从 FPK 包内抽图标（含 `app.tgz` 内 `ui/images`），其次仓库常见路径，统一 512 高清，第三方源不再显示首字母占位
- **安装向导**：开源许可全文与勾选同意、调试端口、应用数据路径、日志路径都在向导内设置
- **数据目录可切换**：索引与配置可迁移到新路径，热切换无需重启
- **备份与恢复**：支持在备份列表中选择历史备份恢复，也可生成最新备份并下载到手机 / 电脑，或从手机 / 电脑上传备份恢复
- **自动备份**：按周期（默认 7 天，可调 1–30 天）自动备份，同一目录保留最近 20 份，可逐份下载 / 恢复 / 删除
- **应用日志**：设置页内置日志卡片——查看、复制、刷新、清理（保留 1 / 7 / 30 天或全部）、按级别筛选、行数 50–1000 可调
- **清理**：一键清除数据（清空应用索引、保留配置），需二次确认；Moo 里的 moo-mate 源会在下次同步时随之清空
- **应用内自更新**：下载新包 → 校验 `.sha256` → minisign 验签，任一不过一律拒绝（fail-closed），数据保留
- **移动端适配**：手机上操作按钮均分排布，日志与备份列表按窄屏重排
- **复用 Moo 的 GitHub Token**：无需在 Moo Mate 里再填一份 Token

## 安装

### 通过 FnDepot 源安装

1. 打开 Moo → 「应用源」→ 添加 `FnDepot` 源（`https://github.com/Blue-Mink/FnDepot`）
2. 在应用列表中找到 **Moo Mate**，点击安装
3. 平台会按你的 CPU 架构自动选择 x86 或 arm 包

### 通过 Moo 源安装

若已添加本仓库或其它含 Moo Mate 的源，直接在 Moo 中搜索 **Moo Mate** 安装即可。

### 手动安装

下载上面对应架构的 `.fpk`，在飞牛 OS「应用中心 → 手动安装」中选择该文件。
安装前可用 `.sha256` 校验完整性：

```bash
sha256sum -c moo-mate_0.2.50_x86.fpk.sha256
```

## 使用步骤

1. 安装完成后，在飞牛 OS 桌面或应用中心打开 **Moo Mate**（首次安装会有向导：许可协议 → 端口与数据 / 日志路径）
2. 在首页「粘贴仓库链接」里贴入要收录的仓库地址（每行一个，最多 10 个），点「开始」
3. 已发布 `moo.json` / `fnpack.json` 的仓库会与 Moo 现有源比对去重；没有索引的会自动扫描 release 与仓库目录里的 `.fpk` 生成索引
4. 在「应用索引列表」里逐个推送或批量推送，把应用加入本机 Moo 的 moo-mate 源
5. 回到 Moo 刷新目录，即可看到并安装这些应用；之后在 Moo Mate 里点「同步更新」即可跟进上游新版本

## 说明

- **自更新**：从 GitHub Release 拉取新包后先校验 `.sha256`，再用内嵌 minisign 公钥验签；缺任一侧车或校验失败一律拒绝升级（fail-closed），数据保留。也可手动下载 FPK 覆盖安装
- **Token 复用**：GitHub Token 直接读取本机 Moo 的配置，Moo Mate 侧无需单独填写，也不会写入日志与备份
- **端口**：默认 `38108`，仅监听 `127.0.0.1`，通过平台网关 `/app/moo-mate` 访问；向导内可改
- **数据**：索引与配置存放在应用数据目录，可在设置里改到任意 `/volN` 目录；升级安装会保留，卸载并删除数据将一并清除
- **Gitee 频控**：Gitee 开放接口有频率限制，短时间大量探测会返回 403，此时目录扫描退化为「仅 release」，稍后重试即可
