# 冬瓜HAOS

在 fnOS 系统中创建同架构的 Home Assistant OS 虚拟机，享受 KVM 硬件加速性能。

## 安装方式

在飞牛 FnDepot 应用源中搜索「冬瓜HAOS」即可安装，或下载 FPK 包手动安装。

## 安装说明

安装后请在「虚拟机」应用中启动/停止虚拟机。

## 访问方式

- **Home Assistant Web UI**: http://虚拟机IP:8123
- **冬瓜HAOS 伴侣**: http://虚拟机IP:8124

## 首次安装

安装向导可配置：
- CPU 核心数（1-16）
- 内存大小（1024-65536 MB）
- 磁盘大小（16-256 GB）
- HAOS 版本
- 是否开机自启

## 注意事项

- 需要已安装并运行 `trim.vm`（虚拟机应用）
- 仅支持 x86_64 架构
- 首次启动需要等待几分钟 HAOS 初始化
- 通过 VNC 可在「虚拟机」应用中查看启动过程
