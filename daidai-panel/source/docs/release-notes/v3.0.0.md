# v3.0.0
<!-- release-title: 全屏扁平 UI 改版、调度并发闸门修复与脚本可调用面板 -->

## 版本概览

`v3.0.0` 是 `v2.3.8` 之后的大版本。界面整体改为全屏铺满的扁平直角风格；调度器修好了一个长期存在但完全静默的缺陷——「定时任务最大并发数」和「不允许多实例」此前从未真正生效；脚本现在可以直接回调面板；Magisk 模块新增 Debian(glibc) 版本，安装失败也不会再谎报成功。

## 新增

- **UI 全屏铺满 + 纯扁平改版**：去掉圆角、阴影、渐变与悬浮上浮，页面铺满整个视口，不再有外框留白。环形图改为横向堆叠条，底部页脚移除。
- **Docker 镜像拆分精简版与完整版**：自 `v3.0.0` 起提供 10 个正式浮动标签。默认标签是精简版；需要跑 Go 任务、装需现场编译的依赖或换 Debian 运行时，请用 `-full` / `-debian-full` 档位。
- **脚本可以直接回调面板**：任务运行时新注入 `DAIDAI_API_BASE` 与 `DAIDAI_TOKEN`，发通知、读写环境变量、查任务日志、触发订阅拉取都不必再申请 Open API 应用。用法与三种语言的可复制示例见[脚本内调用面板能力](../script-api.md)。
- **环境变量支持按名字写回**：新增 `PUT /api/v1/envs/by-name`，语义与 `ddp env set` 对齐——不存在则建、存在一条则改、**存在多条直接报错**（多条同名意味着多账号，整段写回会破坏结构）。
- **Magisk 模块新增 Debian(glibc) 版本**：每次发版多出一个 `daidai-panel-magisk-debian-vX.Y.Z.zip`。面板「一键安装 Python / Node 运行时」下发的是 glibc 预构建，在原来的 Alpine(musl) 容器里根本执行不了（实测 0/2），只有 Debian 版能用上。**两个版本只能装一个**，默认仍推荐体积更小的 Alpine。
- **Magisk 模块支持 Android 6.0**：门槛从 API 24 降到 23。真正的准入不再是版本号，而是安装时实际进容器跑一条命令探测——失败会立刻中止并给出排查方向，不用等装完重启才发现起不来。
- **原始日志支持服务端直传下载**：大日志不再需要先在浏览器里渲染完才能保存。
- **Linux 压缩包随包提供 `ddp` 命令行**：四个架构的 `tar.gz` 里都带上了，解压即用。
- **环境变量超限诊断**：脚本报 `Argument list too long` 时，面板会指出是哪些环境变量超过了单条 128KB 上限，而不是留下一句看不懂的报错。

## 优化

- **日志加载不再卡顿**：渲染从 O(n²) 降到线性，大日志实测提速 353 倍。
- **脚本编辑器加载更稳**：Monaco 改为本地与 CDN 并行探测，加载失败时给出可操作的提示而不是无限转圈。
- **订阅拉取状态区分成功 / 失败 / 已终止**：不再只有一个「已完成」，git 失败会归类出具体原因（网络、认证、限流等）。
- **README 重构为可折叠结构**：落地页从 700 多行收到约 156 行，细节按需展开。
- **补上后端测试门禁**：`go vet` 与 `go test` 现在会在 CI 上跑，此前只跑前端构建。

## 修复

- **修复「定时任务最大并发数」与「不允许多实例」从未真正生效**：调度器此前只在派发阶段计数，任务一启动就释放了名额，所以并发数填 1 还是 128 都不限制。现在名额会一直持有到任务真正结束（含全部重试），重复触发也会被拒绝。
- **修复并发数改完要重启面板才生效**：现在保存即生效。调大立刻补足，调小则让多余线程在两次任务之间自行退出，不会打断正在运行的任务。
- **修复开机任务一拥而上**：随机延迟恢复对开机任务生效（此前被误连同手动执行一起跳过）。配合并发数设为 1，开机任务会按任务排序逐个执行。
- **修复关机被运行中的任务拖住**：现在先中断子进程再回收调度线程，不用等满超时。
- **修复订阅白/黑名单不支持 `|` 分隔**：青龙风格的 `"jd_|jx_|jddj_"` 此前会被当成一个整体，导致拉取 0 个文件、创建 0 个任务。
- **修复关闭订阅拉取弹窗后状态卡在「运行中」**。
- **修复注入脚本的面板令牌有效期长达一年且无法作废**（安全）：未设超时的任务此前拿到的是一年期令牌，且签发时丢弃了令牌 ID，面板自己都无法吊销。现在改为用完立刻作废、有效期只做兜底（7 天），`ddp python` / `ddp shell` 与脚本调试运行同样覆盖。
- **修复过期的令牌黑名单记录从不清理**：现在随既有的日志清理周期一并清除。
- **修复 Magisk 模块安装失败却报告成功**：此前不检查 `rurima` 是否存在、装依赖整段无退出码检查、最后无条件打印「安装完成！」。现在装完会实际验证 `python3` / `node` / `npm` / `git` / `bash` 可用，缺哪个列哪个，全部通过才报成功。
- **修复 Watchtower 与镜像变体的更新链路不一致**。
- **修复企业微信应用 mpnews 图文消息正文不换行**：正文里的换行现在会正确转成 `<br>`；描述等纯文本字段不受影响。
- **修复 Edge/Chromium 下点击最小化被强制拉回全屏**：窗口最小化时上报宽度 0 会被误判为移动端，已加守卫。
- **修复桌面版 Python 版本缺失直接启动失败**：配置的版本本机没装时，会自动回退到已安装的受支持版本并在日志中提示。
- **修复多设备登录后旧会话无限加载**：被顶下线的旧会话现在会正确失效并跳转登录页。

## 破坏性变更

- **「定时任务最大并发数」首次真正生效（默认 5）**：升级前这个开关形同虚设，升级后同时运行的任务最多 5 个，其余排队。任务多的用户会直观感到「变慢了」，这是修复不是退化，需要更高并发请到 设置 里调大。
- **卡死的任务会占用并发名额**：升级前一个 hang 住的任务不影响别的任务，升级后会一直占着名额。请给可能卡死的任务设置「超时时间」。
- **Magisk 模块不再接受 x86_64 设备**：模块自带的容器运行时只有 AArch64 构建，此前 x86_64 设备能通过检查却在启动容器时失败，安装器还照样报成功。现在会被明确拦截。如果你的 x86_64 设备此前「装成功」过——那个面板本来就没跑起来。
- **青龙 `dependence` 参数改为功能性**：`ql repo` 的第 4 个参数命中的文件现在会被拉取到脚本目录但**不注册为任务**（辅助库语义）。此前该参数存了却全链路不读，导致 `sendNotify.js`、`utils/` 这类辅助文件不落盘、任务一跑就因缺依赖失败。同时路径片段支持目录递归。

## 升级说明

- 升级后请确认「定时任务最大并发数」是否够用——它现在是真实的同时执行上限。想让开机任务按顺序跑，把它设为 1 并用任务排序决定先后；此时需把这些任务的「随机延迟秒数」显式设为 0，否则延迟到期顺序会覆盖排序。
- 手动执行任务不再等待随机延迟属于预期变化；定时与开机运行仍按配置错峰。
- Docker 用户请确认镜像标签档位：默认标签是精简版，需要 Go / 编译工具链 / Debian 运行时请切到 `-full` 或 `-debian-full`。
- Magisk 用户按需选择 Alpine 或 Debian 版。**Debian 版没有模块卡片一键更新**（两个版本共用同一模块 id，`updateJson` 只能指向一个），请手动下载 Debian ZIP 升级。
- 二进制部署的用户升级后，安装目录里会多出一个 `ddp` 文件，属于预期变化。

## 验证

- 后端回归测试：调度并发闸门（串行、峰值上限、单实例拒绝、运行中计数、延迟不占名额、开机排序、关机耗时、热生效扩缩容）、脚本令牌生命周期（TTL 上界、结束与 panic 后均吊销、运行中保持有效）、环境变量 upsert 三分支、青龙 `|` 分隔白名单与 `dependence` 递归检出。
- 并发闸门与关机顺序另做了突变验证：把闸门改回旧行为后相关用例确定性变红，确认不是「永远为真」的假断言。
- Magisk 脚本：去除行尾符后 `sh -n` 与 `dash -n` 双验、shellcheck 无 error，另有 13 条静态断言锁住架构闸门、能力探测与 flavor 分支。
- 前端构建与类型检查（`npm run build` + vue-tsc）通过。
- 最终发布前执行：`go test ./...`、`npm run build` 与 `scripts/release-preflight.ps1 -Version 3.0.0`。

> **未经真机验证的部分**：Magisk 的 Android 6.0 支持与 Debian 版容器均无 Android 真机测试条件。本项目能保证的是「装不上时会明确告诉你哪一步失败」，而不是「一定能跑起来」。遇到问题请带安装日志开 issue。
