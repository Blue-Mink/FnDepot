## kms-activator —— 已于 2026-09-16 恢复上线（v1.1.10）

2026-09-15 曾因下列原因下线（原文见本目录 git 历史与提交说明）：

| 下线理由 | 现状 |
| :--- | :--- |
| 非 root 运行下 1688→11688 端口转发无法生效，界面默认命令打 1688，主流程不可用 | **已修**：v1.1.0 起直接绑定标准端口 1688（root 仅用于 bind，随后降权），不再依赖任何 nat 规则；端到端以 vlmcs 客户端实测返回真实 ePID |
| 卸载/停用路径不清理 nat 规则 | **已消除**：不再创建 nat 规则，设备上 `iptables -t nat` 为 0 条 |
| `vlmcsd.kmd` 密钥库文件实际缺失 | **已消除**：现版本不引用该文件 |
| 署名指向名下并无该应用仓库的账号 | **已改**：maintainer / distributor 均为 Blue-Mink，并链接 FnDepot 项目 |
| `platform` 与图标槽位不规范 | **已改**：`platform=x86`，补齐 `icon_0/64/128/256/512` 并按尺寸重绘 |
| 打包内 `vlmcsd` 为 stripped 二进制，无源码、无构建配方、无可核验的上游 tag/checksum | **仍是边界**：沿用上游发布的二进制，未自行编译；已在 `kms-activator/README.md`「已知边界」中公开说明，并提供可自行编译替换的路径 |
| KMS 激活工具在公开应用索引中分发的条款与政策风险 | **仍是边界**：属发布者的风险判断，README 已加合规提醒（仅限自有设备的 VOL 批量许可场景） |

> 注：早期审计里「`vlmcsd private build` 字样疑为篡改」一条**不成立**——从上游源码自行编译的客户端同样打印该串，它是分支的 VERSION 特征，不是篡改证据。仍然成立的是「stripped、无溯源、原署名非上游作者」。
