# CS-3D A70 「柔光」 设计文档

> 商店图标定稿方案：Card Stack 立体方案 A（柔光）× 折叠间距 0.070
> 定稿日期 2026-09-20 · 已装机 192.168.3.2 store-icons 1.3.0（入口 `store-icons.cs3da70`）

## 1. 语义

一叠正在被翻阅的应用卡片：前卡摊开在最上面，露出 2×2 应用格子，其中左上格
「当前应用」被点亮发光；后方两张卡片依次错开露出顶缘，表达"堆叠 / 收藏 / 获取"。

| 元素 | 位置（x0, y0, x1, y1） | 圆角 |
|---|---|---|

## 3. 光影模型（单一顶部光源）

| 手法 | 参数 |
|---|---|
| 卡面受光渐变 | 后卡白 α0.135→0.06，中卡 α0.225→0.10，前卡 (52,64,84)→(21,28,39)，均为上亮下暗 |
| 顶缘高光 | 描边环仅保留顶部渐隐带：后卡 α0.40 / 中卡 α0.55 / 前卡 α0.28（band 0.03–0.055，线宽 0.0035–0.004） |
| 接触投影 AO | 遮挡卡顶缘处最深、按距离衰减（幂 1.5）：后卡带 0.042/α0.55，中卡带 0.052/α0.62，裁剪进被遮卡片蒙版 |
| 前卡描边 | 线宽 0.012，纵向渐变 α 上 0.85 → 下 0.34 |
| 点亮格发光 | 白格本体渐变 (255,255,255)→(244,247,251)，外圈 σ≈10px 白色柔光 α0.30；其余三格白 α0.56→0.40 |
| 底板 | 石墨蓝 tint (11,12,15) + 顶部辉光 (30,34,42)·k^1.8 − 10·y²下压 + 顶部 17 阶白色环境光坡 |

## 4. 圆角蒙版管线

官方 224 点左剖面 → Savitzky-Golay(11,3) 去量化噪声 → cos² smoothstep 交界曲率渐消
（尾端 14 节点，κ 峰值 0.503→0.288）→ 上半镜像强制上下对称 → PCHIP 样条插值 →
4× 超采样多边形填充 → BOX 降采样 → 0.5px 高斯 AA（过渡带约 2px）。
实现：`hd_mask2.alpha_poly(size, ss=4)`。

## 6. 复现

```bash
cd work/store_icon

```

## 7. 迭代记录（为什么是这一版）

- 平面叠色版被判「不立体」→ 引入渐变+AO+顶缘高光；首版 AO 坡向写反（远端最深）
  在后卡顶部压出黑线，修正为"接触边最深、向上衰减"
- B（悬浮投影）/ C（厚卡边）/ D（玻璃层叠）同批出图，用户选 A（焦点干净、小尺寸稳、
  单一光源逻辑自洽）
- 间距 0.062 → 0.080 试过后定 0.070（三层读得清且不松散）
- A2（前卡顶缘高光提亮半档）对比后未选
